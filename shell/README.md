# Shell Integration

Generate hooks from the binary instead of sourcing tracked shell scripts:

```sh
taskglance hooks zsh --alias tg
taskglance hooks bash --alias tg
taskglance hooks fish --alias tg
```

Installed completion files are generated by CMake install:

```sh
share/zsh/site-functions/_taskglance
share/bash-completion/completions/taskglance
share/fish/vendor_completions.d/taskglance.fish
```

For custom prefixes, make sure the relevant completion directory is visible to
your shell. For example, zsh users installing to `~/.local` usually need:

```sh
# Before compinit.
fpath=("$HOME/.local/share/zsh/site-functions" $fpath)
```

Hooks are still evaluated or sourced from your shell startup file after
`taskglance` is on `PATH`.

The generated `tg` shortcut is optional. `taskglance` remains the canonical
command.
