# Security Policy

## Supported Versions

Until the first stable release, security fixes are made on the latest version
of `main`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's private vulnerability reporting form in the Security tab.

Include the affected command, expected and observed behavior, and a minimal
reproduction when possible. Reports will be acknowledged as soon as practical
for this solo-maintained project.
