# AGENTS.md

Technical guidance for Codex and other coding agents working in this repo.

## Project

`taskglance` is a C++20 terminal task reminder CLI. It is a fresh rewrite
inspired by `kindjie/zsh-todo-reminder`, with shell-neutral behavior and
public-repo hygiene.

## Tooling

- Build system: CMake, documented at https://cmake.org/documentation/
- Language: C++20, compiled locally with Apple Clang during initial setup.
- Tests: CTest, via `ctest --test-dir build`.

## Commands

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build
```

## Standards

- Prefer 80-column width and 2-space indents.
- Keep runtime dependencies out of v1 unless there is a strong reason.
- Do not add network behavior.
- Do not persist ANSI escape sequences in task data.
- Keep `taskglance` as the canonical executable; `tg` is an optional shell
  alias generated by hooks.
- Run tests before committing.
